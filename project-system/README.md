# Project System navigation

Project System packages and demonstrates Framework through reusable guidance without redefining Framework. The [Framework context package](../framework/docs/context-package.md#7-skill-system) owns the eighteen-skill inventory and lifecycle; the [constitution](../framework/docs/constitution.md) governs normative meaning.

## Start and use

- [Goal-oriented recipes](docs/recipes.md): new-product planning, bounded bugs, small internal tasks, QA and safe pickup from one normal checkout.
- [Skills](skills/): read the matching `SKILL.md` and apply it directly when prerequisites are clear. The orchestrator is an optional router, not a mandatory preamble.
- [Templates](templates/): twenty existing artifact filenames; use the full stack or an adequate compact contract as the project needs.
- [Optional local helpers and manual fallbacks](tools/README.md): conservative PR observation, task/evidence checks and factual worktree inventory. No installation or helper is required to use BuildSolid.

## Examples

- [Photographer SaaS](examples/photographer-saas/README.md): synthetic full-stack planning and legacy compatibility; no implemented or deployed application.
- [Execution and verification pilot](examples/execution-pilot/README.md): runnable local CLI, browser and performance procedures with deliberate controls. Instructions and planned coverage are separate from the operator's actual results.
