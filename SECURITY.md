# Security policy

## Release scope

This policy covers the BuildSolid Framework and Project System at the exact commit selected by the current annotated version tag. An untagged commit is a candidate. BuildSolid is in ongoing feature development; a prerelease is not a claim of production readiness.

Report vulnerabilities in a downstream product to that product's maintainer through its own security process.

## Report a vulnerability privately

On this repository's GitHub page, open the **Security** tab and choose **Report a vulnerability**. Submit the report through that private interface.

Do not disclose a vulnerability in a public Issue, pull request or Discussion. Do not put secrets, private repositories, customer data or exploit details in a public channel.

If the private reporting option is unavailable, wait for a verified private reporting channel. Do not post the report publicly.
