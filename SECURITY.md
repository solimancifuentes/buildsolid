# Security Policy

## Supported release

The supported BuildSolid release is the exact commit selected by the current annotated version tag. An untagged commit is a candidate and has no released authority.

## Report a vulnerability privately

On this repository's GitHub page, open the **Security** tab and choose **Report a vulnerability**. Submit the report through that private interface.

Do not disclose a vulnerability in a public Issue, pull request, or Discussion. Do not include secrets, private repositories, customer data, or exploit details in a public channel.

If the private reporting option is not available, do not post the report publicly. Wait for a verified private reporting channel.

## Scope

This policy covers the BuildSolid Framework and Project System files in this repository. A vulnerability in a downstream product built with BuildSolid should be reported to that product's maintainer through its own security process.
