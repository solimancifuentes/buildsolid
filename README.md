# BuildSolid

BuildSolid is a software factory framework and intelligence layer for building real software with AI.

This standalone distribution is a self-sufficient Markdown Git tree. It contains the normative Framework plus a compatible Project System of skills, templates, and one synthetic worked reference example. The example is illustrative scenario material, not evidence of conducted research, implementation, deployment, or launch. The package requires no product CLI, API, package, runtime service, database, hosted platform, or publication automation.

## Start here

Read these paths in order:

1. `AGENTS.md` — public-tree working guidance.
2. `framework/README.md` — Framework navigation.
3. `framework/docs/constitution.md` — normative BuildSolid rules.
4. `framework/docs/context-package.md` — workflow and Development contracts.
5. `framework/docs/brand/BUILD_SOLID_CANONICAL.md` — identity and positioning.
6. `project-system/README.md` — skills, templates, and reference-example navigation.

Use `project-system/skills/buildsolid-orchestrator/SKILL.md` when entry or cross-stage routing is unclear. A focused skill may be used directly when its genuine prerequisites are already established.

## What is included

The Framework defines a fourteen-stage lifecycle, three project profiles, and four interaction modes. The Project System provides fourteen Markdown skills, twenty templates, and a twenty-one-file synthetic photographer SaaS reference example.

Framework owns normative BuildSolid meaning. Project System packages and demonstrates Framework without redefining it.

## Release authority

An untagged commit is a candidate. Released authority belongs only to the exact commit selected by the matching annotated `v0.5.0` tag. A GitHub Release is presentation for that tagged commit; it does not select a different tree.
