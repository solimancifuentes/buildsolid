# BuildSolid

BuildSolid is a free, open-source Markdown framework for spec-driven software development with AI.

It provides Markdown instructions, skills, templates, and a fictional worked example to help people clarify an idea, define requirements, plan implementation, and review decisions.

I created BuildSolid as part of my personal learning and exploration of AI-assisted development, and shared it so others could use and adapt the approach. I intend to keep it free and open source. There are no paid offerings or current plans to commercialize the project.

BuildSolid supplies guidance and project documents. People and their chosen AI tools carry out the software implementation, with human review throughout.

## Project status

The v0.5.0 release is complete. I intend to make occasional documentation and security corrections, with no planned feature development.

BuildSolid remains an experimental resource. The published v0.5.0 release is designated as a prerelease, not as stable or production-ready. The worked example illustrates the workflow; it does not establish real-world effectiveness or guarantee that an AI agent will follow every instruction.

## What is included

The Framework defines a fourteen-stage lifecycle, three project profiles, and four interaction modes. The Project System provides fourteen Markdown skills, twenty templates, and a twenty-one-file synthetic photographer SaaS reference example.

The example is illustrative scenario material, not evidence of conducted research, implementation, deployment, or launch.

The framework is a self-sufficient Markdown package with no application or product runtime code. The current default branch also includes an optional Cursor environment configuration that checks checkout files. It is development setup, and is not required to use the framework from a normal checkout.

Framework owns normative BuildSolid meaning. Project System packages and demonstrates Framework without redefining it.
